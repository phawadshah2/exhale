# Home, Details and Logs (Oct 2026)

Live canvas (private, owner only until shared):
https://claude.ai/artifact/Es7ju6TWmMj5pkNon4tbHu

Figma (editable frames, 4 sections):
https://www.figma.com/design/KMF3WeQgfFv5g2MhOiwXMM

These files are a copy of that canvas. Each `*.dc.html` is one 390 px wide
phone screen; open it in a browser to view it. `canvas.json` holds the
layout. The canvas is the source of truth; refresh this copy when it changes.

Spec: `docs/superpowers/specs/2026-10-21-home-details-logs-design.md`

| --- | --- |
