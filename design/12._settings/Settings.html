4. Lifetime

No plan changes. This also fixes the review note "Lifetime over Annual hides Manage": if a subscription is still renewing, the sheet says so and offers to cancel it.

What's new in code: "Request a refund" (StoreKit 2's refund sheet) needs one new store method, and so does the "still renewing" check behind the Lifetime note. Everything else uses what StoreRepository already has: manageSubscriptions, purchase and restore. "Redeem a code" opens Apple's own code sheet (no new store logic, one call). It also belongs on the paywall and the locked screen, since a friend with a code meets the paywall before they ever see Settings.
Lapsed: no change. The locked screen still covers the app, and its Restore stays there.
